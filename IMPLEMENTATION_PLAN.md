# Delivery plan

## Milestone 1 — Starter PWA and schema
- [x] Responsive installable-web-app shell
- [x] Property-specific Autopilot response timeline UI
- [x] Tenant-aware database schema and RLS baseline
- [x] Research evidence and source register schema
- [x] Approval request and audit log schema
- [ ] Real authentication screens and account provisioning
- [ ] Production migration review and RLS tests

## Milestone 2 — Live Washington data
- [ ] Build official-source adapters county by county
- [ ] Start with Whatcom, Kittitas, Clallam, Spokane, Chelan, Snohomish and Thurston
- [ ] Add assessor/GIS/auditor/treasurer/court index adapters where lawful and technically accessible
- [ ] Record source dates, update frequency, terms and access constraints
- [ ] Deduplicate parcel records and track redemption/withdrawal updates

## Milestone 3 — AI research worker
- [ ] Queue and worker execution
- [ ] Structured tool outputs with evidence references
- [ ] Property response generation
- [ ] Agent run timeline and retry/error handling
- [ ] Confidence calibration and human-review flags

## Milestone 4 — Underwriting and portfolio
- [ ] Comparable sales retrieval and manual comp overrides
- [ ] Repair and carrying-cost assumptions
- [ ] Rental income, vacancy, expenses, DSCR and cash-on-cash
- [ ] Flip margin and wholesale MAO
- [ ] Creative-finance payment scenarios
- [ ] Portfolio and deal comparison

## Milestone 5 — Public subscriptions
- [ ] Stripe products/prices
- [ ] Checkout and customer portal
- [ ] Signed webhook processing
- [ ] Entitlement enforcement and usage metering
- [ ] Terms, privacy, cancellation and support

## Milestone 6 — Production release
- [ ] Domain and hosting
- [ ] HTTPS, backups, monitoring and error alerts
- [ ] Security review and penetration testing
- [ ] Android install testing
- [ ] Public launch checklist

## Non-negotiable safety gate
No agent can contact a person, send an offer, sign or submit a document, pay money or initiate a transaction. The product must stop at research, analysis and draft preparation unless a separately designed, legally reviewed, explicitly approved workflow is later implemented.
